# Design System UI Harness

Profiles component libraries, tokens, Storybook/source examples, and UI constraints so Codex can build or review UI against actual source-of-truth assets.

## Agents

- Source Auditor
- Component Inventory Agent
- Token Agent
- UX Flow Agent
- Frontend Builder
- Storybook Agent
- Accessibility Agent
- Visual QA Agent
- Repair Agent
- Finalizer

## Validators

- `component_inventory`
- `token_usage_detected`
- `raw_color_detection`
- `valid_import_paths`

## Outputs

- `component-inventory.json`
- `design-system-conformance.md`
- `validation-report.md`
- `harness-trace.json`
- `skill-update-suggestions.md`
